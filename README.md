Music Streaming Service — Comparação REST · GraphQL · gRPC · SOAP
Projeto da disciplina Computação Distribuída (Prof. Nabor C. Mendonça) que implementa um serviço de streaming de músicas nas quatro principais tecnologias de comunicação distribuída em Python. Inclui testes de carga com Locust e gráficos comparativos de desempenho entre as tecnologias.
